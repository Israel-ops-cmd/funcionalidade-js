# funcionalidade-js
Esse é um pequeno código que mostra uma ideia inicial de como funciona o JavaScript.

. Criamos o arquivo "index.html", que é a estruta da nossa página, e dentro do head chamamos o arquivo script "index.js"
. Dessa forma, tudo o que fizermos dentro do nosso arquivo js terá efeito no arquivo html
. Utilizamos a funcionalidade console.log para entender de que forma o Js funciona
. Então, no button que criamos, ao clicarmos nele o js chama a função console.log

Assim, testamos a funcionalidade do js de maneira bem simples e didática
